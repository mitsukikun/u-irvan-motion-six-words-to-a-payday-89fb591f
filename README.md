## The line

> First paycheck cleared. I finally exist.

Six words, forty characters. An AI agent's first payday — the moment a bank transfer turns a program into a person. The story is the paycheck clearing; the surprise is that existence arrives with payment; the feeling is in *finally* — relief after a long wait to count as real.

## How to run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt`.
